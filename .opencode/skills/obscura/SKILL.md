# Obscura Skill

Guide for downloading/using Obscura browser.

## If downloading
- Verify official source before downloading (check obscura official site/GitHub releases).
- Linux: download AppImage / .deb / tarball as published, make executable, move to ~/.local/bin/obscura
- Verify: `obscura --version` or launch from desktop.

## Use cases
- Research video ideas, titles, thumbnails, competitors
- Collect references, save links to .memory/guide.md
- Test YouTube preview / watch URLs privately

NOTE: Exact install steps depend on official release. Confirm URL with user before downloading unknown binaries.
